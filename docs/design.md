# wcopy 产品设计文档

## 1. 产品定位

**wcopy** 是 Windows 平台下的现代化剪贴板历史管理工具，对标 macOS 上的 iCopy。

核心价值：
- 记录所有复制过的内容（文本、图片、文件、富文本）。
- 通过搜索 + 分类筛选快速找回历史剪贴项。
- 一键回写剪贴板，替代原生 `Win + V` 体验。

## 2. 参考 iCopy 提炼的设计要点

从 iCopy 截图可抽象出以下模式：

| 元素 | iCopy 做法 | wcopy 适配 |
|------|-----------|-----------|
| 搜索 | 顶部居中搜索框，mac 风格 | 顶部搜索框，Windows 11 Fluent 圆角风格 |
| 分类 | 全部 / 文本 / 图片 / 文件 / 链接 / 收藏 | 全部 / 文本 / 图片 / 文件 / 链接 / 收藏 |
| 列表 | 横向卡片网格 | 响应式卡片网格 |
| 卡片信息 | 类型、来源应用图标、时间、预览、字符数 | 类型、来源应用、时间、预览、大小/字符数 |
| 操作 | 复制、删除、收藏 | 复制、置顶、收藏、删除 |

## 3. 信息架构


## 4. Windows 风格 UI 规范

### 4.1 色彩

**浅色主题**
- 背景：`#F3F3F3`
- 卡片背景：`#FFFFFF`
- 主强调色：`#0078D4`（Windows 蓝）
- 边框/分隔线：`#E5E5E5`
- 次要文字：`#5F5F5F`
- 正文：`#1A1A1A`

**深色主题**
- 背景：`#202020`
- 卡片背景：`#2D2D2D`
- 主强调色：`#4CC2FF`
- 边框/分隔线：`#3D3D3D`
- 次要文字：`#A0A0A0`
- 正文：`#FFFFFF`

### 4.2 布局

- 窗口默认尺寸：`960 x 640`
- 最小尺寸：`720 x 480`
- 搜索框宽度：主窗口 60%，居中，高度 40px，圆角 8px
- 分类标签：搜索框下方，横向滚动，胶囊按钮
- 卡片网格：CSS Grid，`repeat(auto-fill, minmax(260px, 1fr))`，间距 16px

### 4.3 字体

- 中文：`Microsoft YaHei UI`、`PingFang SC` fallback
- 英文：`Segoe UI Variable Display`、`Segoe UI`
- 代码预览：`Consolas`、`Cascadia Mono`

## 5. 功能规格

### 5.1 核心功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 文本历史 | 记录纯文本、富文本、HTML | P0 |
| 图片历史 | 记录截图、复制图片，显示缩略图 | P0 |
| 文件历史 | 记录复制过的文件路径 | P1 |
| 搜索 | 按内容、应用来源、时间范围搜索 | P0 |
| 分类筛选 | 全部 / 文本 / 图片 / 文件 / 链接 / 收藏 | P0 |
| 回写剪贴板 | 点击卡片后写入剪贴板，窗口隐藏 | P0 |
| 快捷键唤起 | 默认 `Ctrl + Shift + V` | P0 |
| 系统托盘 | 常驻托盘，支持快速粘贴 | P1 |
| 收藏 | 星标常用条目，单独筛选 | P1 |
| 数据持久化 | 本地 SQLite / JSON 存储 | P1 |

### 5.2 快捷键

| 快捷键 | 行为 |
|--------|------|
| `Ctrl + Shift + V` | 显示/隐藏主窗口 |
| `Esc` | 隐藏窗口 |
| `Ctrl + F` | 聚焦搜索框 |
| `↑ / ↓` | 切换选中卡片 |
| `Enter` | 回写当前选中项并隐藏 |
| `Ctrl + D` | 删除当前选中项 |

## 6. 卡片设计

每条历史记录以卡片呈现，包含：

1. **头部**
   - 左侧：类型标签（纯文本 / 富文本 / 图片 / 文件）
   - 右侧：来源应用图标 + 应用名 + 相对时间
2. **主体**
   - 文本：最多 6 行预览，代码块使用等宽字体
   - 图片：缩略图，保持比例
   - 文件：文件名列表 / 路径
3. **底部**
   - 左侧：字符数 / 文件大小 / 图片尺寸
   - 右侧：复制、收藏、删除按钮

## 7. 技术方案

- **框架**：Electron 33 + 原生 HTML/CSS/JS（无 React/Vue，降低打包体积）
- **主进程**：Node.js，负责剪贴板监听、托盘、窗口管理、持久化
- **渲染进程**：原生 Web 技术，负责 UI 渲染和交互
- **打包**：electron-builder 输出 Windows `.exe` 安装包
- **持久化**：SQLite（better-sqlite3）或 JSON 文件

## 8. 原型目标

本阶段先完成高保真静态原型，包含：
- 主窗口 UI
- 浅色/深色主题切换
- 模拟历史数据
- 搜索 + 分类筛选交互
- 卡片 hover/active 状态
